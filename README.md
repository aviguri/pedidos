# Pedidos AVIGURI

App web de toma de pedidos y ruteo de Grupo CTS / AVIGURI.

- **Página:** https://aviguri.github.io/pedidos/
- **Datos:** viven en una planilla de Google privada. Se accede a través de un puente de Apps Script protegido con clave.
- **Este repositorio:** contiene solo el código de la página (`index.html`). No contiene datos ni claves.

Cada usuario entra con su link personal o cargando el link y la clave en **Conexión**.
